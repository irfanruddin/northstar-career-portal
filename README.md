# Northstar Careers — Frontend MVP

A browser-based career/job application portal built with HTML, CSS and vanilla JavaScript.

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Features
- Candidate login/register
- Candidate dashboard
- Job search and filters
- Job details
- Job application form
- My applications and status tracking
- Candidate profile
- Admin job creation
- Admin application status management
- localStorage persistence

## Important
This is a frontend MVP. Authentication and resume handling are NOT production-secure because data is stored in localStorage.
The next development phase should replace localStorage with a Node.js/Express API and MySQL database.
